⚡ Ek baar setup karo (3 minute)

  1. console.firebase.google.com kholo → Add project → naam do → Create
  2. Left menu → Build → Firestore Database → Create → Start in test mode → Enable
  3. Left menu → Build → Storage → Get started → test mode → Done
  4. ⚙️ Project settings → Your apps → </> Web → register → jo firebaseConfig mile, wo is file ke top pe paste kar do

Firestore Rules:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /files/{doc} { allow read, write: if true; }
  }
}

Storage Rules:

rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /uploads/{file=**} { allow read, write: if true; }
  }
}
